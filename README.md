# Mind Trainer — тренажер пам'яті

Локальний PWA-застосунок для тренування пам'яті. Без серверів і баз даних: усе працює в браузері, дані в `localStorage`. Контент генерується заново кожного запуску (seeded PRNG), а з ключем Claude API ще й реалістичні сюжети, наближені до життя.

## Запуск

Потрібен будь-який статичний сервер (service worker не працює з `file://`).

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Відкрийте http://localhost:8765. На телефоні: відкрити ту саму адресу в локальній мережі (або задеплоїти папку на GitHub Pages / Cloudflare Pages) і «Додати на головний екран».

## Вправи

| Вправа | Що тренує | Рівень |
|---|---|---|
| 📖 Історія дня | Епізодична пам'ять на реальному матеріалі: імена, час, місця, числа | кількість фактів |
| 🧑‍🤝‍🧑 Люди та імена | Асоціативна пам'ять (обличчя → ім'я, професія, місто) | кількість людей |
| 🛒 Список справ | Відкладене пригадування + інтервальне повторення | довжина списку |
| 🔁 N-back | Робоча пам'ять (подвійний n-back: позиція + символ) | N |
| 🟦 Просторова послідовність | Просторова робоча пам'ять, прямий і зворотний порядок | довжина |
| 🎯 Подвійне завдання | Робоча пам'ять під розділеною увагою | кількість цифр |
| 🗺️ Маршрут | Просторова і послідовна пам'ять з орієнтирами | довжина шляху |

Принципи, закладені в дизайн:

- **Процедурна генерація.** Кожна сесія з нового seed. Запам'ятати «відповіді» неможливо.
- **Адаптивна складність (staircase).** ≥80% → рівень +1, <50% → рівень −1. Окремий рівень на кожну вправу.
- **Інтервальне повторення.** Списки та факти з історій повертаються через 10 хв → 1 год → 1 день → 3 дні.
- **Реалістичний контент.** Через Claude генеруються нові сюжети, люди і списки; офлайн працюють вбудовані банки.
- **Щоденник і прогрес.** Сон, рух, настрій, самооцінка пам'яті; графіки точності та рівнів; експорт у JSON.

## AI-шар

Налаштування → вставити ключ Claude API. Ключ зберігається тільки у `localStorage` і відправляється напряму на `api.anthropic.com` (заголовок `anthropic-dangerous-direct-browser-access`). Сервера-посередника немає, тому ключ не варто використовувати на чужих пристроях.

- Модель за замовчуванням `claude-opus-5-5`, у налаштуваннях можна вибрати Sonnet або Haiku для економії.
- Відповіді у форматі structured outputs (JSON schema), тому парсинг надійний.
- Контент кешується наперед (prefetch), тож ігри стартують швидко.
- Увімкнено server-side fallback на випадок відмови класифікатора безпеки.

## Структура

```
index.html        оболонка
manifest.json     PWA
sw.js             офлайн-кеш статичних файлів (API-запити не кешуються)
css/style.css
js/app.js         екрани: головна, результат, щоденна сесія, відкладені перевірки, щоденник, прогрес, налаштування
js/rng.js         seeded PRNG
js/storage.js     localStorage: налаштування, рівні, результати, spaced-черга, щоденник, AI-кеш
js/adaptive.js    staircase
js/ai.js          виклики Claude API + prefetch
js/content.js     офлайн-банки та шаблонні генератори
js/games/*.js     вправи, кожна експортує meta і start(done)
```

Додати нову вправу: створити `js/games/name.js` з `meta = {id,title,icon,desc,defLevel}` та `start(done)`, що викликає `done({game, level, accuracy, score, seed, details})`, і додати в масив `GAMES` у `app.js`.

## Застереження

Застосунок не є медичним виробом. Відновлення пам'яті після алкоголю передусім залежить від тверезості, тіаміну (B1), сну, фізичної активності. Тренажер доповнює це, а не замінює.
